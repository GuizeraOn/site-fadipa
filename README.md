# 🦷 Sorriso Consciente — Cárie: Menos é Mais

> **Projeto de Extensão Universitária — FADIPA 2025**  
> Divulgação Científica e Popularização da Odontologia Minimamente Invasiva: Remoção Seletiva de Cárie em Cavidades Profundas.

---

## 📖 Sobre o Projeto

O **Sorriso Consciente** é uma plataforma educativa desenvolvida por discentes e docentes do curso de Odontologia da **FADIPA (Faculdade de Odontologia de Ipatinga)**. O objetivo é desmistificar conceitos antigos sobre a remoção agressiva de cáries e conscientizar o público leigo e a comunidade acadêmica sobre os benefícios biológicos da **Remoção Seletiva de Tecido Cariado**, evitando tratamentos de canal desnecessários e preservando o dente natural vivo.

### 🌟 Destaques e Funcionalidades
- **Design Moderno:** Inspirado na estética limpa e funcional do *Claude-Cookbook* (paleta clínica, cards minimalistas, badges discretos).
- **Animações Dinâmicas:** Transições de scroll, micro-interações e modais com física de mola elástica usando `Framer Motion`.
- **Anatomia Interativa das 3 Camadas:** Seletor anatômico interativo (Esmalte, Dentina e Polpa).
- **Simulador Comparativo:** Demonstração visual entre a Abordagem Agressiva Antiga e a Remoção Seletiva Moderna.
- **Mitos vs. Verdades:** Cards 3D interativos com efeito flip (toque no celular ou clique no desktop).
- **Baseado em Evidências:** Resumo dos estudos clínicos de 5 anos (Jardim, Petta, Miotti, Barros) e modal com referências formais (ABNT/Vancouver).
- **Mobile-First & Acessibilidade para Eventos:** Inclui gerador de QR Code na tela para visitantes escanearem via celular no evento presencial.
- **Integração com Google Forms:** Chamada de destaque e barra flutuante inteligente (*Smart Floating CTA*) direcionando para a coleta de opiniões da pesquisa.

## 🛠️ Tecnologias Utilizadas

- **React 19** + **Vite**
- **Tailwind CSS**
- **Framer Motion** (Animações de entrada, acordeão fluido e transições de layout)
- **Lucide React** (Ícones modernos)

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/GuizeraOn/site-fadipa.git
   cd site-fadipa
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Gerar build de produção:**
   ```bash
   npm run build
   ```
